A tiny Node 22 program for the make.fun bounty
[Make the AI Judge Laugh: Office Jokes](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a).

`main.ts` writes one office joke to `/output/entry.txt`: HR claims the
open-plan office encourages collaboration — which is how the narrator now
knows Dave's dentist, divorce, and lunch order. A genuine office joke with
a surprise turn at the end, instant recognition for anyone who has sat in
an open-plan office, tight wording, and a fresh angle — no Monday-morning
or photocopier cliché. No network, no randomness, no input — the same line
on every run.

Run it with Node 22:

```sh
node main.ts
```
